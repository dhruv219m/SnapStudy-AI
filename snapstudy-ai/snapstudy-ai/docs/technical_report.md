# Technical Summary

## Problem
Cloud AI is useful for studying but can expose private notes and requires connectivity.

## Solution
SnapStudy AI provides a local-first workflow for PDF notes and relevant passage retrieval, with a planned local language-model generation layer.

## Snapdragon relevance
The application is intended for Snapdragon-powered HP PCs. The optimization phase will evaluate compact quantized models, compatible runtimes and hardware acceleration.

## Current status
Functional local retrieval prototype. Snapdragon/NPU deployment is a planned stage and should only be claimed after real hardware testing.
